# Outfit H5 前端产品需求文档（MVP）

> Outfit · 姐姐衣风录\
> 衣有万象，风雅如初。

## 1. 产品定位

Outfit 是一本会成长的数字衣风录。

记录： - 衣物 - 穿搭 - 图集 - 生活故事

核心理念：

> 衣会旧，风格会成长，而生活值得被记录。

## 2. 前端目标

MVP 优先打造移动端 H5 产品体验：

用户可以： - 浏览自己的穿搭作品 - 查看衣风录章节 - 查看穿搭故事 -
管理个人衣橱

## 3. 技术形态

用户端： - Vue3 - TypeScript - Vite - Vant4 - Pinia - Vue Router

管理端： - Vue3 - TypeScript - Element Plus

## 4. 用户端导航

底部 Tab：

-   首页
-   衣风录
-   穿搭
-   衣橱
-   我的

## 5. 页面需求

### 首页

展示： - 品牌 Banner - 今日风格 - 最近穿搭 - 数据概览

示例：

晚风知意

傍晚的风，比任何情话都温柔。

### 衣风录

核心页面。

展示：

《姐姐·衣风录》

章节： - 第一卷 · 春风有信 - 第二卷 · 都市知性 - 第三卷 · 夜色轻熟 -
第四卷 · 东方雅韵

### 穿搭列表

形式： - 图片瀑布流 - 穿搭卡片

内容： - 封面 - 名称 - 文案 - 标签

### 穿搭详情

展示：

-   大图
-   穿搭故事
-   场景
-   风格标签
-   搭配单品
-   图集

接口：

-   GET /outfit/{id}
-   GET /outfit-item/list
-   GET /outfit-image/list

### 我的衣橱

展示：

-   衣物图片宫格
-   分类筛选
-   季节筛选

接口：

-   GET /dict/category
-   GET /dict/season

### 我的

展示：

-   用户信息
-   穿搭数量
-   衣物数量
-   设置

## 6. API 模块

src/api：

-   auth.ts
-   user.ts
-   outfit.ts
-   clothes.ts
-   tag.ts
-   file.ts
-   dict.ts

## 7. 设计原则

关键词：

-   温柔
-   知性
-   留白
-   摄影感
-   东方美学

避免：

-   电商风
-   强营销
-   社交炫耀

## 8. MVP 开发顺序

第一阶段： - 登录 - 首页 - 衣风录 - 穿搭列表 - 穿搭详情

第二阶段： - 衣橱 - 图片上传 - 编辑功能

第三阶段： - 管理后台

## 9. 验收目标

用户打开产品后：

像翻开一本属于自己的生活摄影集。
